# 사진 보관 개인정보 안내 (초안)

> 상태: 초안. 법률 검토와 소유자 확인 전이며 공개 처리방침(`balmatchum-legal`)에는 아직 반영하지 않았습니다.
> 아래 수치는 현재 코드 기준입니다(`server/lib/src/photos/photo_endpoint.dart`).

## 처리방침 문안 초안

**수집하는 항목**
발맞춤 앱에서 사진을 고르거나 찍으면, 앱이 긴 변 1600픽셀 이하의 JPEG로 줄인 사본을 회원님의 계정에 보관합니다.
함께 저장하는 정보는 사진 파일, 파일 크기, 가로·세로 픽셀 수, 올린 시각입니다.
위치 정보(EXIF) 없이 다시 인코딩한 사본만 올리며, 원본 파일은 기기 밖으로 보내지 않습니다.

**이용 목적**
회원님이 올린 사진을 다시 보고 꾸밀 수 있도록 보관하기 위해서만 사용합니다. 다른 회원에게 공개하거나 광고·분석에 사용하지 않습니다.

**보관 위치**
Amazon Web Services(AWS) S3의 아시아 태평양(시드니, `ap-southeast-2`) 리전 비공개 저장소에 저장합니다.
사진은 공개 주소가 없으며, 로그인한 본인에게만 10분 동안 유효한 서명 주소로 제공됩니다.
※ 국외 이전 고지 항목(이전 국가: 호주, 이전받는 자: Amazon Web Services, Inc., 이전 방법: 앱 업로드 시 네트워크 전송, 보유 기간: 아래와 같음)으로 처리방침에 기재해야 합니다.

**보유 및 파기**
- 회원님이 사진을 지우면 저장소의 파일과 기록을 즉시 지웁니다.
- 회원 탈퇴 시 계정의 모든 사진 파일과 기록을 탈퇴 처리와 함께 지웁니다.
- 업로드를 끝내지 못한 파일은 1시간 안에 자동으로 지웁니다.
- 데이터베이스 백업(최대 35일)에는 사진 기록(파일 정보)이 남을 수 있으나 사진 파일 자체는 백업에 포함되지 않습니다.

## 확인이 필요한 점 (소유자)

1. 국외 이전 고지 문구와 동의 방식(별도 동의 필요 여부) 법률 확인.
2. S3 버킷 버전 관리(versioning)가 꺼져 있는지 확인. 켜져 있으면 삭제 후에도 이전 버전이 남습니다.
3. 계정당 사진 500장, 파일당 5MB 제한을 처리방침에 적을지 결정.
4. 시드니 리전 선택 이유(무료 플랜 리전 제한)와 향후 서울 리전 이전 계획 여부.
